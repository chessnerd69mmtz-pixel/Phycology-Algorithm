Ary AI

Conversation intelligence and psychology analysis for your own WhatsApp data. Download the Windows package, enter your own AI provider keys, connect WhatsApp, and run Ary AI locally.

Download Ary AI 8.24.2 View GitHub repository
01 · DOWNLOAD

Get the Windows package

Download the release ZIP, extract it, and keep the folder together. The package includes the Windows launcher and setup scripts.

02 · KEYS

Use your own API keys

Run SET AI API KEYS.cmd. Your keys are stored locally in .env; this repository contains no private provider key.

03 · RUN

Start Ary AI

Run Ary AI Execute.cmd, then connect WhatsApp when the QR is shown. The cloud AI path is Mistral first, with Groq fallback.
